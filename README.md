Atlas of mouse placental isoforms covering the E12.5 and E19.5 periods in both syngeneic and semi-allogeneic pregnancies.

The dataset described in this paper is available as an interactive Vitessce dataset at (https://vitessce.io/#?edit=false&url=https%3A%2F%2Fperiklab-mouse-placenta-atlas.hf.space%2Fconfig.json).

Single-cell gene expression data have been deposited in the Gene Expression Omnibus database under accession code GSE326887 (https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE326887).
